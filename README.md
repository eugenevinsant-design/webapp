# ECG Meta Narrator

Интеллектуальная платформа для визуализации, разметки и анализа электрокардиографических (ЭКГ) сигналов.

## 🚀 Основные возможности

- **Анализ ЭКГ:** Загрузка 12-канальных сигналов через wfdb и генерация клинической аннотации.
- **Чат-интерфейс:** Взаимодействие с нейросетью через текстовые запросы (команды `\choose_pkg`).
- **Оценка и перегенерация:** Возможность оценить ответ модели (0-10) и запросить новый вариант.
- **Аутентификация:** Регистрация по нику с выдачей персонального токена для доступа к API.
- **История:** Сохранение всех шагов и оценок в PostgreSQL.

## 🛠 Технологический стек

- **Backend:** Python 3.11, FastAPI, SQLAlchemy (async), Alembic.
- **База данных:** PostgreSQL 15.
- **Frontend:** Vanilla JS, HTML5, CSS3 (без фреймворков, для максимальной скорости).
- **Инфраструктура:** Docker, Docker Compose, GitHub Actions (CI/CD).
- **Работа с ЭКГ:** Библиотека wfdb (PhysioNet).

## 📦 Быстрый старт

1. Клонируйте репозиторий.
2. Скопируйте `.env.example` в `.env`.
3. Запустите контейнеры:
   `docker compose up -d --build`
4. Откройте в браузере: `http://localhost:8000`

## 🧪 Тестирование

Для запуска тестов выполните:
`docker compose exec backend pytest tests/ -v`
